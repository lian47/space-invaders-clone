# Space Invaders Clone

![Space Invaders Gameplay](src/assets/gameplay.gif)

## Jogar Online
- [Clique aqui para jogar no navegador](https://lian47.github.io/space-invaders-clone/)
  
Uma recriação do clássico jogo Space Invaders desenvolvida em HTML5 Canvas e JavaScript.

## Tecnologias
- HTML5 Canvas
- CSS3
- JavaScript (ES6+)

## Funcionalidades
- Movimentação e disparos do jogador
- Grid de inimigos animados
- Barreiras de proteção destrutíveis
- Sistema de vidas, partículas e Game Over

## Controles
- Mover nave: Teclas A e D
- Disparar: Enter

Projeto desenvolvido para fins de aprendizado.
